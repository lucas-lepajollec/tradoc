# Support

Start with the [README](README.md), [public commands](COMMANDS.md) and the [documentation](https://docs.tradoc.lucas-homelab.fr). Search existing [GitHub issues](https://github.com/lucas-lepajollec/tradoc/issues) before opening a new report.

For a reproducible problem, include the TraDoc commit or version, deployment method, document format, provider type, model identifier, sanitized reproduction steps and relevant logs. Never attach a private document, provider credential, full prompt, database, private endpoint or log containing confidential content. A minimal synthetic document is preferred.

Questions already answered in the documentation or reports that cannot be reproduced may be closed. Suspected vulnerabilities must follow [SECURITY.md](SECURITY.md), not a public issue.
